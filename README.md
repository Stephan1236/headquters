# Headquters website

A responsive multi-page website for Headquters, a growth-operations company focused on helping teams turn strategy into momentum.

## Pages

- `index.html` — Home, product overview, results, and pricing
- `solutions.html` — Planning, reporting, and workflow solutions
- `about.html` — Company story and principles
- `contact.html` — Contact details and demo form
- `portal.html` — Client workspace dashboard with initiatives, metrics, and activity

## Run locally

From the project root:

```bash
python -m http.server 8000
```

Then open http://localhost:8000 in your browser.
